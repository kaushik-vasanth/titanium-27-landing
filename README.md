# TITANIUM 2027 — Official Landing Page

> **India's Largest Tech Fest** · February 2027  
> Presented by **Rajalakshmi Engineering College (REC)**, Chennai, Tamil Nadu, India.

---

## 🚀 Overview

This repository contains the standalone, dedicated landing page interface for **TITANIUM 2027**. Engineered with a high-performance procedural space environment, smooth scroll-driven flight journey, and pre-launch telemetry notification conduits.

### Key Capabilities

1. **Unconstrained Atmospheric Interface:**
   - Architectural fixed top navigation rail with electric-cyan active markers and illuminated pips.
   - Symmetrically balanced wings: Left (`Explore`, `Workshops`, `Speakers`) | Center (`TITANIUM Emblem Disc`, `REC Mark`, `2027`, `"INDIA'S LARGEST TECH FEST"`) | Right (`Exhibits`, `Schedule`, `Get Pass`) | Far Right (`Sign In`).
   - Authentic festival metadata dock with shortcuts, procedural Web Audio synthesizer drone toggle, and verified official social links.

2. **Procedural Three.js Cosmic Environment:**
   - 5,200 procedural twinkling stars, procedural cosmic nebula, and night-side Earth with continental landmasses, glowing city lights, and atmospheric limb scattering.
   - Cursor-responsive pointer parallax and dynamic camera descent pitch.

3. **3-Stage Scroll-Driven Journey:**
   - **Stage 1 — ORBIT:** High-altitude cockpit view with countdown clock and unclipped, spacious **EXPLORE** and **GET PASS** hero action cards.
   - **Stage 2 — DESCENT:** Camera dive into terrestrial atmospheric entry (`13.01°N 80.00°E`) with festival metrics (09 Tracks, ₹10L+ Bounty, 15K+ Delegates, 50+ Institutions).
   - **Stage 3 — THE EXPERIENCE:** Surface terminal showcasing the 5 core festival arenas (Event Catalogue, Workshops, Speakers, Exhibits, Schedule).

4. **"Gates Not Opened // Access Sealed // Will be notified" Conduits:**
   - Every sector interaction triggers an immersive telemetry chamber overlay informing delegates that gates are sealed under orbital calibration.
   - Integrated notification conduit allows delegates to submit their email address to receive priority dispatch when gates unlock.

## 🛠️ Technology Stack

- **Core:** Modern Vanilla JavaScript (ES Modules), HTML5, CSS3 Container Queries & Grid
- **3D Graphics:** [Three.js](https://threejs.org/) (Custom WebGL procedural shaders, zero external 3D textures)
- **Audio:** Web Audio API (Dual-oscillator 55Hz / 82.4Hz lowpass ambient drone synthesizer, zero network dependencies)
- **Tooling:** [Vite](https://vitejs.dev/)

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/kaushik-vasanth/titanium-27-landing.git
cd titanium-27-landing

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
